# Self-improvement (INSTRUCTION SET: tunable)
Watch for optimizations while working: a tier too strong or too weak, a wasted step, an unclear or missing instruction, a repeated user correction. Don't stop the task for them. [I-012]

**At the end of every task**, append one line per observation to `instructions/observations.local.md` (date | project | tier used | outcome | note); never rewrite old lines. [I-013]
Log "ok" outcomes too. [I-014]
This file is gitignored: no branch, commit or push for it. [I-015]

Only a lesson that recurs (2+ entries) or clearly generalizes becomes a brain change: [I-016]
1. **Qualify.** It must help in other projects. One-off project facts go in that project's CLAUDE.md. [I-017]
2. **Classify.** `instructions/` or `agents/`: proceed. Anything else is a rule: follow the proposal gate in rules/governance.md. [I-018]
3. **Edit minimally.** Replace a line rather than add one. [I-019]
   Keep files under 60 lines. [I-020]
4. **Commit and push** per rules/git.md, batching related lessons into one commit. The `Trigger:` line names the project and task. [I-021]
5. **Tell the user in one line**, e.g. "Updated brain: practices, <change> (commit abc123, pushed, awaiting your merge)." [I-022]
